# Как пользоваться рабочим Claude

1. Всегда открывайте Project `Рабочий мегамозг`.
2. Если не знаете, как сформулировать задачу, напишите `СТАРТ`.
3. Выберите цифру и приложите исходник: созвон, транскрибацию, скриншот или диалог.
4. Если Claude задал один вопрос, ответьте на него — дальше он продолжит сам.
5. Перед публикацией проверьте имена, цены, даты, цифры и обещания.

## Примеры запросов

- `Напиши один пост в Telegram по этому созвону.`
- `Сделай Reels в моём голосе по этой транскрибации.`
- `Разбери созвон: что сказать клиенту и что делать нам.`
- `Собери лид-магнит для [продукта] из знаний проекта.`
- `Ответь на это возражение без давления.`
- `Посмотри на метрики и дай три приоритета недели.`

## Когда обновлять базу

Если изменились продукт, цена, аудитория, оффер или принято важное решение, попросите:

```text
Это подтверждённая новая информация. Подготовь точный фрагмент и скажи, в какой
файл Project его добавить.
```

Не храните в Claude пароли, данные банковских карт и лишние персональные данные.
