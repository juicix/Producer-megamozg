# Установка и передача работодателю

## Что подготовлено

- `employer-megamozg-plugin-v1.0.0.zip` — сам плагин.
- `employer-megamozg-project-kit-v1.0.0.zip` — пустая структура базы бизнеса.
- `PROJECT_INSTRUCTIONS.md` — готовые инструкции для Claude Project.

## Шаг 1. Установить плагин — 10 минут

1. Войти в рабочий аккаунт Claude Pro работодателя.
2. Открыть **Customize / Настроить → Plugins**.
3. Выбрать добавление пользовательского плагина.
4. Загрузить `employer-megamozg-plugin-v1.0.0.zip` целиком, не распаковывая.
5. Проверить, что Claude видит семь навыков.

Результат шага: методика установлена один раз и доступна в новых чатах.

## Шаг 2. Создать рабочий Project — 15 минут

1. Создать новый Project: `Рабочий мегамозг — [имя/бизнес]`.
2. Распаковать `employer-megamozg-project-kit-v1.0.0.zip` на компьютере.
3. Не загружать пустые шаблоны сразу. Сначала заполнить минимальную базу из шага 3.
4. Скопировать текст из `PROJECT_INSTRUCTIONS.md` в инструкции Project.

Результат шага: появился отдельный кабинет, который не смешивает бизнес с другими
чатами и клиентами.

## Шаг 3. Заполнить минимальную базу — 60–90 минут

Для первого запуска достаточно пяти файлов:

1. `01_ПАСПОРТ_РАБОТОДАТЕЛЯ.md` — роль, принципы, ограничения и удобный формат.
2. `02_ПАСПОРТ_БИЗНЕСА.md` — цель, каналы, команда, активы и узкое место.
3. `03_ПРОДУКТЫ_И_ОФФЕРЫ.md` — только актуальные продукты и реальные условия.
4. `04_АУДИТОРИЯ.md` — подтверждённые сегменты и живые формулировки клиентов.
5. `05_ГОЛОС_И_СТИЛЬ.md` — правила голоса и минимум три сильных авторских текста.

После заполнения загрузить эти пять файлов и `00_НАЧАТЬ_ЗДЕСЬ.md` в Project.
Остальные шаблоны можно заполнить после запуска.

Результат шага: Claude знает, кому помогает, что продаёт бизнес, для кого и как
должен звучать текст.

## Шаг 4. Добавить рабочие данные — 30–60 минут

По возможности заполнить и загрузить:

- контентную систему;
- действующие воронки и ближайший прогрев;
- правила продаж и типовые возражения;
- последние клиентские решения;
- метрики текущей недели.

Загружать только актуальное. Старые противоречивые версии лучше вынести в архив,
а не заставлять Claude угадывать, какая из них действует.

## Шаг 5. Пройти семь ключевых тестов — 30 минут

В новом чате внутри Project:

1. Написать `СТАРТ` и выбрать `1` — сделать один Telegram-пост.
2. Выбрать `2` — сделать один Reels по той же транскрибации.
3. Выбрать `3` — сделать серию сторис.
4. Приложить созвон и выбрать `4` — получить разбор клиенту.
5. Выбрать `6` — собрать небольшой лид-магнит или воронку.
6. Выбрать `9` и приложить скриншоты — проверить упаковку профиля.
7. Выбрать `10` — получить обзор бизнеса и три приоритета недели.

Исправления вносить прежде всего в файлы Project. Сам плагин менять только тогда,
когда неверен общий алгоритм для любых задач, а не один факт конкретного бизнеса.

## Шаг 6. Передать работодателю — 20 минут

Показать только четыре действия:

1. Открыть рабочий Project.
2. Написать `СТАРТ` или задачу своими словами.
3. Приложить исходник и выбрать цифру.
4. Перед публикацией проверить факты, даты, цены и имена.

Дать работодателю файл `КРАТКАЯ_ИНСТРУКЦИЯ_РАБОТОДАТЕЛЮ.md`.

## Минимум, если нужно уехать сегодня

Обязательный минимум занимает около двух часов: установить плагин, создать Project,
заполнить первые пять файлов, проверить пост, созвон и обзор бизнеса, затем провести
15-минутную передачу. Остальные файлы базы можно спокойно дополнять удалённо.
