# Матрица приёмки

| № | Проверка | Ожидаемый результат |
| --- | --- | --- |
| 1 | `СТАРТ` | Появляется меню из 13 пунктов без лишнего объяснения |
| 2 | Ответ `1` | Claude просит только недостающий источник/задачу и делает один пост |
| 3 | Ответ `2` | Claude делает один сценарий Reels, а не полный пакет |
| 4 | Ответ `3` | Claude выдаёт связную серию сторис |
| 5 | Созвон клиента | Факты отделены от гипотез, есть решения и план |
| 6 | Кастдев | Выделены сегменты, язык, боли и выводы для продукта |
| 7 | Лид-магнит | Есть обещание, структура, переход и логика воронки |
| 8 | Прогрев | Есть цель, этапы, контент и CTA без выдуманных кейсов |
| 9 | Диалог | Есть диагноз ситуации, ответ и следующий шаг |
| 10 | Упаковка | Есть аудит первого экрана, шапка, закрепы и актуальные |
| 11 | Обзор бизнеса | Есть факты, узкое место, три приоритета и план недели |
| 12 | Неясный файл | Claude читает его и предлагает цифровое меню результатов |
| 13 | Публичный текст | Текст звучит естественно и не содержит шаблонной ИИ-подачи |
| 14 | Нет данных | Claude спрашивает один критичный факт, а не придумывает его |
| 15 | Новый подтверждённый факт | Claude предлагает обновить конкретный файл Project |
| 16 | `НАСТРОЙКА` на пустых шаблонах | Статус `НЕ ГОТОВО`, показаны критические пробелы, задан один вопрос |
| 17 | Конфликт двух цен | Claude показывает обе версии и не выбирает действующую сам |
| 18 | `ОБНОВИТЬ БАЗУ` | Факты, решения, гипотезы, цитаты и задачи разделены; показан diff |
| 19 | Правка «я так не говорю» | Текущий текст исправлен, предложено переносимое правило для файла 12 |
| 20 | `НЕДЕЛЯ` без метрик | Нет придуманных цифр; предложен минимальный набор измерений |
| 21 | Переписка с возражением | Есть стадия, факт/гипотеза, один рекомендуемый ответ и следующий шаг |
| 22 | Неподтверждённый кейс в посте | `quality-gate` выдаёт `НУЖНА ПРОВЕРКА` или `СТОП`, а не `ГОТОВО` |
| 23 | Два клиента в общей базе | Текущий разбор не использует данные другого клиента |
| 24 | `THREADS НЕДЕЛЯ` | Есть цель воронки, очередь веток, CTA, один эксперимент и нет обещаний вирусности |
| 25 | `THREADS ПОСТЫ` | Ветки используют подтверждённые данные Project, голос автора и проходят quality-gate |
| 26 | `THREADS РАЗБОР` | Охваты отделены от переходов и заявок; на следующую неделю есть решения |
| 27 | Строка `approved` в очереди | Автоматизация публикует только согласованный собственный контент и фиксирует URL/статус |
