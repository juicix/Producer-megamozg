# Рабочий мегамозг для Claude Pro

Один плагин закрывает повседневную работу экспертного бизнеса: Telegram, Reels,
сторис, клиентские разборы, кастдевы, лид-магниты, воронки, прогревы, диалоги,
упаковку профиля и еженедельный обзор бизнеса.

## Установка за 10 минут

1. Откройте Claude → **Customize / Настроить** → **Plugins**.
2. Выберите установку пользовательского плагина и загрузите ZIP плагина.
3. Убедитесь, что доступны семь навыков: `navigator`, `producer-megamozg`,
   `content-zavod`, `client-review`, `profile-packaging`,
   `storytelling-corrector`, `antidetector`.
4. Создайте отдельный Claude Project для бизнеса.
5. Заполните и загрузите в Project файлы из комплекта `project-template`.
6. Вставьте текст из `PROJECT_INSTRUCTIONS.md` в инструкции проекта.
7. Откройте новый чат внутри Project и напишите `СТАРТ`.

Для короткой передачи работодателю используйте PDF-памятку из релиза или соберите
её командой:

```powershell
python .\scripts\build-quick-guide.py
```

Плагин хранит методику и сценарии работы. Claude Project хранит меняющиеся данные
конкретного бизнеса. Обновлять плагин после каждого созвона не нужно.

## Главное правило

Не загружайте в общий плагин клиентские базы, пароли, платёжные данные и другие
секреты. Материалы конкретного бизнеса и клиентов должны оставаться в его Project.

## Обновление

При выходе новой версии замените установленный ZIP. Файлы Claude Project при этом
не удаляются. Перед заменой сохраните локальную копию актуальных файлов проекта.
