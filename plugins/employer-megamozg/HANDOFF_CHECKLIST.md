# Передача кабинета работодателю

- [ ] Плагин установлен и отображается в Claude.
- [ ] Создан один рабочий Claude Project.
- [ ] В Project загружены заполненные файлы базы.
- [ ] Инструкции проекта вставлены без сокращений.
- [ ] Команда `НАСТРОЙКА` не показывает критических пробелов.
- [ ] Команда `СТАРТ` показывает понятное меню.
- [ ] Протестированы пост, Reels, сторис и разбор созвона.
- [ ] Протестированы лид-магнит, прогрев и обзор бизнеса.
- [ ] Если используется Threads: заполнены цель канала, рубрикатор и очередь публикаций.
- [ ] Если используется автопубликация: опубликован один тестовый пост со статусом `approved`.
- [ ] Работодатель умеет приложить файл и выбрать цифру.
- [ ] Работодатель знает, куда складывать новые материалы.
- [ ] Работодатель умеет использовать `ОБНОВИТЬ БАЗУ` и подтверждать diff.
- [ ] Для каждого клиента создаётся отдельный чат.
- [ ] Назначен человек, который раз в неделю обновляет базу.
- [ ] Локально сохранены ZIP плагина и комплект проекта.
- [ ] Переданы две короткие инструкции: установка и ежедневная работа.
