# Начните отсюда

После установки откройте чат внутри рабочего Claude Project и напишите:

```text
СТАРТ
```

Claude покажет меню. Можно ответить одной цифрой. Если задача уже понятна, пишите
её обычными словами и прикладывайте материал: транскрибацию, скриншоты, заметки,
диалог или документ.

Примеры:

- `Напиши пост в Telegram по этой транскрибации.`
- `Разбери созвон и подготовь обратную связь клиенту.`
- `Собери лид-магнит для продукта из базы проекта.`
- `Проверь упаковку Instagram по скриншотам.`
- `Посмотри состояние бизнеса и дай три приоритета на неделю.`

Если Claude задаёт вопрос, отвечайте только на него: кабинет настроен так, чтобы
не устраивать длинное анкетирование.
