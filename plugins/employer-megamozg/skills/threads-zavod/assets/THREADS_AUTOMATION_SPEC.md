# Автоматизация публикаций Threads

## Безопасный минимум

1. Claude готовит строку в `THREADS_QUEUE_TEMPLATE.csv` или Google Sheets.
2. Владелец вручную меняет `status` с `draft` на `approved`.
3. Планировщик (Make/n8n/собственная интеграция) выбирает только `approved`-строки с наступившими датой и временем.
4. Планировщик публикует собственный пост через официальный Threads API.
5. При необходимости планировщик публикует один первый комментарий как reply к своему посту.
6. Планировщик записывает URL, ID, фактическое время и статус `published`; при сбое — `error` с текстом ошибки.

## Данные для каждой публикации

- `publication_id` — уникальный ID, не менять после согласования;
- `thread_text` — текст основного поста;
- `first_comment` — необязательный первый комментарий;
- `utm_link` — уникальная ссылка источника;
- `status` — только `draft`, `approved`, `publishing`, `published`, `error`.

## Ограничения

- Не передавать логин, пароль, 2FA-код, App Secret и access token в Claude или таблицу.
- Хранить OAuth-токен только в секретах автоматизации.
- Не публиковать строки без статуса `approved`.
- Перед повтором запроса проверять `publication_id` и уже сохранённый URL, чтобы не создать дубль.
- Не автоматизировать массовые комментарии, лайки, подписки или личные сообщения.
