# Библиотека транскрибаций

Используй эту карту перед чтением исходников. Все файлы лежат в этой папке и доступны одновременно. Ищи по ключевым словам, затем читай только нужные фрагменты.

| Файл | Когда читать | Ключевые слова |
|---|---|---|

| `Charla_Декомпозиция_MP3_28_04_26.txt` | Нужен финансовый план, воронка и расчёт запуска | декомпозиция, выручка, охват, вебинар, конверсия, трафик |

## Правило использования

- По запросу «разобрать запуск» обычно используй: разбор запуска + декомпозиция + прогревы + продажи.
- По запросу «поднять чек» обычно используй: продукт + 10 фишек продаж + кастдевы.
- По запросу «сделать ИИ-кабинет» сначала собери данные проекта, затем используй библиотеку только как методологическую опору; не смешивай клиентские данные с библиотекой.
