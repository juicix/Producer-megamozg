# Producer Megamozg

Переносимый скилл для Codex и Claude: стратегия роста, аудитория, продукт, контент, прогрев, запуск, продажи, команда и ИИ-система экспертного проекта.

## Codex

В PowerShell из папки репозитория:

```powershell
.\scripts\install.ps1
```

Перезапусти Codex после установки. Скилл появится как `producer-megamozg`.

## Claude

Создай архив для загрузки:

```powershell
.\scripts\install.ps1 -PackageForClaude
```

Затем загрузите `producer-megamozg-claude-skill.zip` в Claude: **Customize → Skills → +**. В архиве `SKILL.md` лежит на верхнем уровне, поэтому Claude распознаёт его корректно. После установки скилл можно вызывать в Claude или использовать по смыслу задачи.

Не загружайте в публичный репозиторий записи созвонов, клиентские базы, пароли, выгрузки переписок и другие персональные данные.

## Claude Pro: плагин «Рабочий мегамозг»

Для ежедневной работы руководителя подготовлен отдельный плагин из семи навыков:
контент, Reels, сторис, клиентские разборы, кастдевы, воронки, прогревы, продажи,
упаковка профиля и обзор бизнеса.

Готовые архивы:

- [плагин Claude v1.0.0](dist/employer-megamozg-plugin-v1.0.0.zip);
- [комплект файлов Claude Project](dist/employer-megamozg-project-kit-v1.0.0.zip).

Установка:

1. В Claude Pro открыть **Customize → Plugins**.
2. Загрузить архив плагина без распаковки.
3. Комплект Project распаковать на компьютере.
4. Создать отдельный Claude Project, вставить `PROJECT_INSTRUCTIONS.md` в его
   инструкции и загрузить заполненные файлы базы.
5. В новом чате Project написать `СТАРТ`.

Исходники и подробные инструкции находятся в
[`plugins/employer-megamozg`](plugins/employer-megamozg).
