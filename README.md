# Producer Megamozg

Переносимый скилл для Codex и Claude: стратегия роста, аудитория, продукт, контент, прогрев, запуск, продажи, команда и ИИ-система экспертного проекта.

## Codex

В PowerShell из папки репозитория:

```powershell
.\scripts\install.ps1
```

Перезапусти Codex после установки. Скилл появится как `producer-megamozg`.

## Claude

Создай архив для загрузки:

```powershell
.\scripts\install.ps1 -PackageForClaude
```

Затем загрузите `producer-megamozg-claude-skill.zip` в Claude: **Customize → Skills → +**. После установки скилл можно вызывать в Claude или использовать по смыслу задачи.

Не загружайте в публичный репозиторий записи созвонов, клиентские базы, пароли, выгрузки переписок и другие персональные данные.
